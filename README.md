# Serverside QoL

This mod adds some QoL features as a serverside-only mod.

It's designed and tested for **dedicated servers** with **vanilla/console clients** (e.g. XBox/PS/Switch users).

If you'd like to support me, [subscribe as a test user](https://github.com/ArgusMagnus/ValheimServersideQoL/issues/98).
You can help by testing the beta versions on [hexium](https://valheim.hexium.gg/?q=ArgusMagnus).

## Configuration
The configuration is loaded from `$(ValheimInstallDir)/BepInEx/config/ArgusMagnus.{PluginName}.cfg`. Start the server once to generate the file if it does not exist.
